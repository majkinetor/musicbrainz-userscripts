# musicbrainz-userscripts

This repository contains userscripts to be used with [MusicBrainz](https://musicbrainz.org)

## Scripts

See each script's README for detailed instructions and screenshots:

1. [Import Discogs Credits](./userscripts/discogs_credits/README.md)<br>
UI for importing Discogs credits as MusicBrainz release relationships and few general import helpers.
1. [Platform Check](./userscripts/platform_check/README.md)<br>
Find URLs for a particular MusicBrainz release on online platforms, verify track counts, surface label / year / format alongside.
1. [MagicISRC SoundExchange Search](./userscripts/magicisrc_soundexchange/README.md)<br>
Batch lookup on the MagicISRC using the SoundExchange ISRC database.
1. [ISRC Check](./userscripts/isrc_check/README.md)<br>
Total number of release tracks that have ISRC defined with link to MagicISRC.
