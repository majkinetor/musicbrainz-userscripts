MusicBrainz Toolset

Editing MusicBrainz one entity at a time is fine until the day you have four hundred of them. These are twelve userscripts written for that day: they import credits from other sites, fix relationships by the hundred, chase ISRCs, sort cover art, and merge duplicate recordings — all inside MusicBrainz’s own pages, in the tab you are already in.

Each one works on its own. If you would rather not install them one at a time, String Theory is all of them built into a single file, sharing one settings window. You will need a userscript manager either way.

499,632 edits have been made with these so far, by 136 editors; 99.9% of the ones that closed were applied.

The full statistics are rebuilt from the MusicBrainz database snapshot.
