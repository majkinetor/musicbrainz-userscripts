- 2026-05-23 23:00 — MB's relationship state schema discovered → `re.state.relationshipsBySource` is a **5-level nested immutable tree**: `sourceId → targetType → {typeId, backward, phraseGroups} → {relationships, textPhrase} → rel[]`.
