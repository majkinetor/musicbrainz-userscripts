# ISRC check

Shows release total number of tracks that have ISRC defined. Clicking the button will open [MagicISRC](https://magicisrc.kepstin.ca/) for the release. Use the [magicisrc_soundexchange](../magicisrc_soundexchange/README.md) script afterwards.

- [Install at Greasy Fork](https://greasyfork.org/en/scripts/578255)
