First Contact: Send to Harmony

Mockup for the Harmony option, drawn with First Contact's own button CSS (dark theme). The button sends the album to Harmony (harmony.pulsewidth.org.uk/release?url=…) instead of opening MusicBrainz's release editor. Harmony then looks up the other platforms by barcode, and Falcon carries on from there as it does now.

A. A Harmony button between Import and ⚙︎recommended

One click, always in view, and Import keeps working as it does now. The Harmony icon says where it goes. A setting can hide it. In Icon only mode it's the third square, and with Settings button only on hover the ⚙︎ tab still sits above it.
